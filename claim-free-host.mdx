> Follow the steps below to claim and deploy your free NexCloud server.

### Step 1 — Join Our Discord

Join the official NexCloud Discord server to access the Free Hosting program and receive important updates and support.

[**Join Discord →**](https://discord.gg/Gp9TpKXZ6T)

### Step 2 — Create Your Account

Create your NexCloud account using the required commands.

```text
nc!user new
```

Once your account has been created, log in to the NexCloud [FR Panel](https://panel.nexcloud.in).

### Step 3 — Create Your Server

Create your NexCloud Free Server using the required commands.

```text
nc!server create python
```

```text
nc!server create nodejs
```

Once your server has been created, go to the NexCloud [FR Panel](https://panel.nexcloud.in).

### Step 4 — Configure Your Server

Once your server has been created, open the server management panel.

From there, you can:

- Upload your files
- Configure your application
- Set environment variables
- Install required dependencies
- Start and stop your server
- View server logs

#### Step 6 — Start Your Server

After completing the configuration, start your server from the panel.

Check the console and logs to make sure your application starts correctly.

## You're Ready

Your NexCloud Free Hosting server is now ready to use.

If you encounter any issues while claiming or setting up your server, contact the NexCloud support team through our Discord server.
