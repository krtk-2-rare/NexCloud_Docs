> NexCloud Free Hosting servers require periodic renewal to remain online.

You can renew your free hosting server directly from the Discord by using the **coins**.

### Step 1 — Go to Discord

You can use following commands to know more about renewal.

```text
nc!game
```

We have multiple games to play and get coins.

### Step 2 — Get Info about the Server

Get your server id using the following commands.

```text
nc!server list
```

Get your Server ID from this.

### Step 3 — Renewal

Use your Coins \[ 3K for Renewal \] to renew your free server.

```text
nc!server renew <serverid>
```

This is require to avoid inactive servers to maintain free spaces. 

### Step 4 — Keep Your Server Active

Make sure you renew your server before its expiry period ends.

If the server is not renewed within the required period, it may expire and become unavailable.

> **Tip:** Check your server's expiry date regularly so you don't lose access to your Free Hosting server.

## Need Help ?

If you are unable to renew your server or encounter an issue with the challenge, contact NexCloud Support through our Discord server.
